# 热榜深潜简报 · 求真标签（Chrome 插件）

在知乎热榜（zhihu.com/hot、/billboard）页，给当天被「热榜深潜简报」收录的条目盖上**求真印章**：

- 🟠 吵翻天（真分歧） / 🟣 缺关键证据（待验证） / 🔵 有定论（共识） / 🟢 已实锤（全网核验找到一手材料）
- 鼠标悬停印章：弹出迷你卡（锐评 + 两方金句 + 判读数据日期 + 查看完整深读链接）
- 匹配方式：优先按知乎问题 ID，没有 ID 的按标题前 8 字兜底

## 数据从哪来

插件打开热榜页时，后台从线上站点读取当天的判读（`/data.js`），30 分钟内不重复请求；读取失败时用插件自带的 `data.js` 离线兜底。

- **装一次长期有效**：站点每天更新，插件自动跟上，不用重新打包。
- **悬停卡注明数据日期**：站点还没生成当天简报时，读到的是前一天的快照，卡片会标「前一天快照」；用的是离线兜底时标「离线数据」。
- **权限最小**：只申请 `storage`（缓存判读）和访问本站一个域名；不读取、不上传任何知乎页面内容或用户信息。

## 安装（开发者模式）

1. 打开 `chrome://extensions/`
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」，选择本 `extension/` 目录
4. 打开 https://www.zhihu.com/hot 即可看到印章

## 更新离线兜底数据

```bash
node extension/gen_extension_data.js
```

从 `demo/data.js`（每日归档任务自动刷新的前一天快照）生成 `data.js`，转换规则与后台 `background.js` 共用同一个函数。

## 说明

- MV3；后台 service worker 负责取数与缓存，内容脚本只负责盖章与悬停卡。
- 知乎热榜是单页应用，插件用 MutationObserver 监听翻页与加载后补盖印章。
- 站点地址写在 `background.js` 的 `SITE_URL` 和 `manifest.json` 的 `host_permissions`，换域名时两处一起改。
