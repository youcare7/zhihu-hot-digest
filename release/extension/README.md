# 热榜深潜简报 · 求真标签（Chrome 插件）

在知乎热榜（zhihu.com/hot、/billboard）页，给今日已被「热榜深潜简报」收录的条目盖上**求真印章**：

- 🟠 吵翻天（真分歧） / 🟣 缺关键证据（待验证） / 🔵 有定论（共识） / 🟢 已实锤
- 鼠标悬停印章：弹出迷你卡（锐评 + 蓝橙双方金句 + 查看完整深读链接）
- 匹配方式：优先按问题 ID，站外链接条目按标题前 8 字兜底

## 安装（开发者模式）

1. 打开 `chrome://extensions/`
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」，选择本 `extension/` 目录
4. 打开 https://www.zhihu.com/hot 即可看到印章

## 数据更新

`data.js` 是构建时从 `demo/data.js` 拷贝的子集（只含今日 10 条，不含全文）。
更新内容后重新生成：

```bash
node extension/gen_extension_data.js
```

## 配置

- `data.js` 里的 `site_url`：悬停卡「查看完整深读」的跳转地址。本地预览是 `http://localhost:7100/`，**上线公网后必须改成正式地址**（重新运行生成器或手改）。

## 说明

- MV3，无后台脚本、无网络权限请求，数据打包在插件内，评审断网也能演示。
- 知乎热榜是单页应用，插件用 MutationObserver 监听翻页/加载后补盖印章。
