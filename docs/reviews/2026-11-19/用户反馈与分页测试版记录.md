## 4. 产品决策与落地对照

| 决策 | 对应反馈 | 落地结果 |
|---|---|---|
| 今日判断并入首页 | 长图用户、吴雨乘 | 首页直接显示 headline、三态计数与 insights，不再另设重复的“今日”分页。 |
| 保留 10 条独立分页 | 多数分页偏好反馈 | 每条热点拥有独立页面、编号按钮和 `#card-N` 深链。 |
| 增加目录和筛选 | 芊什猫及直接访问需求 | 目录展示全部标题，可按“仍有分歧 / 已有共识 / 需补材料”筛选并直达。 |
| 保留连续阅读 | 染、宴之敖者 | “连续阅读”展示全部卡片和来源页，避免只能逐页点击。 |
| 三态颜色与文字同时出现 | 长图用户 | 绿 / 橙 / 紫分别对应共识 / 分歧 / 待补材料，但始终附文字，不只靠颜色传达。 |
| 重命名“守卫” | 吴雨乘 | 改为“来源与链接”，正文解释候选编号映射、域名校验和去重。 |
| 手机滑动翻页 | 分页阅读与移动端体验 | 仅识别明确横向手势；垂直滚动不翻页，按钮与键盘仍可用。 |
| 液态玻璃克制使用 | 本轮视觉升级目标 | 仅用于顶部导航、目录和底部分页器；正文保持实色高对比，不嵌套玻璃。 |

## 5. 仍需保留的结论

1. 用户偏好并不一致，不能删除连续阅读而只保留分页。
2. 本轮反馈支持“降低信息负担、改善直接访问”，不支持量化收益或进决赛概率推断。
3. 本地预览使用示例数据；真实内容表现必须另以生产快照和线上验收为准。
4. 后续若扩大样本，建议让用户完成“找到第 5 条”“比较两条争议”“回到今日判断”“打开知乎原文”四个任务，再记录完成情况和卡点，不只问喜欢哪版。
